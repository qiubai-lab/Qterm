BUILT AROUND THE TERMINAL

Arrange your tools around the task.

Split local and remote terminals, files, Git and network panels horizontally or vertically. Switch between workspaces while active sessions stay in place.

SSH connections and credentials

Use passwords, private keys or SSH Agent. Verify new host keys and keep saved secrets in an encrypted vault. Changed trusted host keys are blocked by default.

Port forwarding

Manage local forwarding, remote forwarding and SOCKS5 rules in a Network Block. Start rules when you need them and inspect their status.

Agent notifications

When a tool emits supported OSC 9 or OSC 777 messages, Qterm can surface a notification and take you back to the source terminal. The tool must emit the message itself.

Before you start

Does Qterm include an AI agent?

No. Install and authenticate your chosen CLI on the server. Qterm provides the terminal and surrounding tools; model access and usage costs belong to the selected provider.

Does the online demo connect to my server?

No. It uses fictional sessions and data, runs no real shell commands and establishes no network tunnels. Download the app for real work. The demo currently uses a Chinese interface.

Can I self-host Qterm in a browser?

Yes. A separate, single-user Web runtime is available for deployment in your own environment. Read the container deployment guide (Chinese) for platform, authentication and network requirements.

What is the license?

Qterm is free and open source under GPL-3.0-only. See the license for redistribution and modification terms.
