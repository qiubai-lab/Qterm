Install Qterm

Your workspace, wherever you work. Install the desktop app or self-host with Docker.

macOS · Apple Silicon / Intel

Use the project-maintained Homebrew tap. The app is not currently notarized by Apple; the cask removes its quarantine attribute during installation. Review the tap before trusting it.

# Add the Qterm Homebrew tap
brew tap qiubai-lab/tap
# Trust this tap (Homebrew 6.0+; skip on older versions)
brew trust qiubai-lab/tap
# Install the Qterm desktop app
brew install --cask qterm

brew trust is the one-time step for Homebrew 6.0+; skip it on older versions. Homebrew tap · Homebrew

For a manual DMG install, choose aarch64 for Apple Silicon or x86_64 for Intel, then drag Qterm into Applications. If macOS reports the downloaded app as damaged, see the project’s installation notes.

Linux · x64

SELF-HOSTED / WEB

Docker · Self-hosted Web

Run your own workspace in the browser. Requires an AMD64 Linux host, local Docker Engine and Docker Compose v2 supporting up --wait-timeout.

# Create qterm/ in the current directory and deploy the Web service
curl -fsSL https://raw.githubusercontent.com/qiubai-lab/Qterm/main/scripts/install-server.sh | sh

Run in the parent directory for your deployment. The script creates qterm/, generates a password and prints the access URL after startup (default port 2654). It will not overwrite an existing directory.

HTTP is for trusted networks or VPNs. Public access requires an HTTPS reverse proxy; the browser origin must match QTERM_PUBLIC_ORIGIN. The container runs as root with host networking by default.

Update with Homebrew

# Refresh Homebrew package information
brew update
# Upgrade Qterm to the latest version
brew upgrade --cask qterm

Updates to the third-party tap are fetched by brew update. Back up important configuration before upgrading.

After installation

Save a connection, select it in a Terminal Block and verify the server fingerprint. Then follow the remote agent guide. Qterm is licensed under GPL-3.0-only; the full terms are in the repository.
