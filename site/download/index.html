QTERM / 使用指南

下载 Qterm：macOS、Windows 与 Linux 安装指南

免费开源的远程 AI 开发 SSH 工作台。选择你的系统开始安装；Qterm 不内置 AI 模型或 Agent。

macOS · Apple Silicon / Intel

可使用项目维护的 Homebrew tap。当前应用尚未经过 Apple 公证，cask 会在安装时移除隔离属性；信任 tap 前可先查看其内容。

brew tap qiubai-lab/tap
brew trust qiubai-lab/tap
brew install --cask qterm

brew trust 用于 Homebrew 6.0+ 的一次性确认，旧版可跳过。Homebrew tap · Homebrew

手动下载 DMG 时，Apple Silicon 选择 aarch64，Intel 选择 x86_64，再将 Qterm 拖入“应用程序”。若提示应用“已损坏”，查看项目的 安装说明。

打开最新发布页，选择安装包 →

Windows · x64

从发布页的 Assets 下载 x64 .msi 或 NSIS .exe，运行安装程序并按提示操作。升级时下载新版安装程序运行。

打开最新发布页，选择安装包 →

Linux · x64

Debian / Ubuntu 选择 .deb，使用 RPM 的发行版选择 .rpm，也可选择 x64 .AppImage 并授予可执行权限后运行。升级时安装新版包或替换 AppImage。

打开最新发布页，选择安装包 →

通过 Homebrew 更新

brew update
brew upgrade --cask qterm

先更新第三方 tap，再升级 Qterm。升级前备份重要配置。

安装后做什么

保存连接，在 Terminal Block 中选择目标并核对服务器指纹，然后跟随远程 Agent 教程开始工作。Qterm 使用 GPL-3.0-only，完整条款以仓库许可证为准。
