安装 Qterm

选择桌面客户端，或通过 Docker 自托管 Web 工作台。

macOS · Apple Silicon / Intel

可使用项目维护的 Homebrew tap。当前应用尚未经过 Apple 公证，cask 会在安装时移除隔离属性；信任 tap 前可先查看其内容。

# 添加 Qterm 的 Homebrew 软件源
brew tap qiubai-lab/tap
# 信任此软件源（Homebrew 6.0+，旧版可跳过）
brew trust qiubai-lab/tap
# 安装 Qterm 桌面客户端
brew install --cask qterm

brew trust 用于 Homebrew 6.0+ 的一次性确认，旧版可跳过。Homebrew tap · Homebrew

手动下载 DMG 时，Apple Silicon 选择 aarch64，Intel 选择 x86_64，再将 Qterm 拖入“应用程序”。若提示应用“已损坏”，查看项目的 安装说明。

打开最新发布页，选择安装包 →

Windows · x64

从发布页的 Assets 下载 x64 .msi 或 NSIS .exe，运行安装程序并按提示操作。升级时下载新版安装程序运行。

打开最新发布页，选择安装包 →

Linux · x64

Debian / Ubuntu 选择 .deb，使用 RPM 的发行版选择 .rpm，也可选择 x64 .AppImage 并授予可执行权限后运行。升级时安装新版包或替换 AppImage。

打开最新发布页，选择安装包 →

SELF-HOSTED / WEB

Docker · 自托管 Web

在浏览器中访问自己的真实开发环境。准备 AMD64 Linux 主机、本机 Docker Engine，以及支持 up --wait-timeout 的 Docker Compose v2。

# 在当前目录下新建 qterm/ 并部署 Web 服务
curl -fsSL https://raw.githubusercontent.com/qiubai-lab/Qterm/main/scripts/install-server.sh | sh

在部署数据的父目录执行。脚本新建 qterm/，生成访问密码，并在启动成功后输出访问地址（默认端口 2654）；不会覆盖已有目录。

HTTP 仅适用于受信任内网或 VPN；公网访问需配置 HTTPS 反向代理，访问地址须与 QTERM_PUBLIC_ORIGIN 一致。容器默认以 root 运行并使用 host 网络。

查看完整部署、升级与备份指南 →

通过 Homebrew 更新

# 更新 Homebrew 软件源信息
brew update
# 将 Qterm 升级到最新版本
brew upgrade --cask qterm

先更新第三方 tap，再升级 Qterm。升级前备份重要配置。

安装后做什么

保存连接，在 Terminal Block 中选择目标并核对服务器指纹，然后跟随远程 Agent 教程开始工作。Qterm 使用 GPL-3.0-only，完整条款以仓库许可证为准。
