QTERM / 使用指南

在同一工作区使用 SSH 与 SFTP

终端运行命令，文件面板检查结果。两个面板并排放置，让远程路径、文件与操作目标保持可见。

本页目录

  1. 1. 连接并选择文件目标
  2. 2. 从终端目录打开 Files
  3. 3. 上传与下载
  4. 4. 预览与编辑文本

1. 连接并选择文件目标

在 Terminal Block 左上角选择保存的 SSH 连接并完成认证。通过终端的文件入口打开 Files Block，或从右侧工具轨打开后选择目标。Files 可以选择本机或远程服务器，并建立自己的连接。

检查文件面板的服务器名称与路径；它并不始终与另一个面板使用同一目标。

2. 从终端目录打开 Files

启用 OSC 7 且 Shell 上报当前目录时，从终端打开的文件面板可从该目录开始。进入另一个目录后，可以再次从终端打开相应视图。已打开的 Files 面板有独立的浏览状态，不会被每次 cd 强制改写。

没有目录信息时用路径导航或目录选择器手动定位。OSC 7 的临时 Shell Hook 不修改远端 Shell 配置，但可能被记录到历史中；可以在高级设置中关闭。

3. 上传与下载

先进入目标目录，再将本机文件或文件夹拖入远程文件面板，或使用上传入口。查看传输进度和失败反馈；下载时选择本机保存位置。确认目录读写权限和剩余磁盘空间。

只想把资料交给 CLI Agent 时，在终端粘贴文件 可以上传至暂存位置并插入路径，无需先定位项目目录。

4. 预览与编辑文本

选择文件进行预览，需要修改时进入编辑并保存。处理未保存内容提示后再切换文件。保存影响远程文件本身，后续可从当前目录打开 Git Block 检查差异。

二进制、超大文件或不支持的格式不适合作为普通文本编辑。发生权限错误时先检查服务端权限；不会因为面板打开成功就自动获得写权限。
