QTERM / 使用指南

给远程 Claude Code / Codex 粘贴截图与文件

无需先另开传输工具：在远程终端粘贴本机资料，等上传完成后，把服务器路径交给 CLI Agent。

1. 确认是已连接的远程终端

以下流程面向桌面版 Qterm 的 SSH 终端。先选择服务器并完成认证，确认可以正常输入命令。服务器需要允许 SFTP 及暂存目录写入；Agent 需要能读取上传后显示的路径。

在本地终端粘贴文件得到的是本地路径；本机路径不能直接作为另一台服务器上的文件使用。

2. 复制截图并粘贴

用系统截图工具将图片复制到剪贴板，聚焦 Qterm 的远程 Terminal Block，再使用系统粘贴操作。等待上传进度结束，检查终端输入区的远端路径或 Agent 对图片的显示，再补充你的需求并发送。

3. 复制文件或文件夹

在 Finder、Explorer 或 Linux 文件管理器中复制目标文件或文件夹，在远程终端粘贴。这里需要复制文件对象，而不是复制文件名文本。上传成功后，Qterm 插入远端绝对路径，不会自动执行命令。

如果需要把文件固定放在项目目录中，可以改用 Files 面板：先打开目标目录，再拖入文件或使用上传入口。终端粘贴暂存与向指定目录上传是不同的操作。

4. 检查结果再发送

确认上传完成、路径正确，并告知 Agent 如何使用该资料，例如“参考这个截图调整页面布局”。路径只是文件位置；能否识别图片、读取特定文件格式，由 CLI、模型及其权限决定。

可取消正在进行的上传。上传失败时先排查原因，不要把不完整的路径当作成功结果；上传后的资料仍需按你的服务器数据管理方式处理。

常见问题

  • 只粘贴了文字：剪贴板同时包含文本时采用文本优先；重新复制图片或文件对象后再试。
  • 上传被拒绝：检查 SSH/SFTP 权限、服务器剩余空间、暂存目录写权限和连接状态。
  • Agent 找不到文件：核对 Agent 与终端是否运行在同一台机器及可访问同一文件系统；容器中的 Agent 可能看不到宿主机路径。
  • 上传成功但读不了图片：先确认所用 CLI 和模型支持图片输入。
  • 要指定落盘目录：使用 SFTP Files 面板 上传至已选目录。
