安装 Qterm

选择你的系统，将完整工作台带到本机。

macOS

Apple Silicon / Intel

推荐使用 Homebrew。当前应用尚未经过 Apple 公证，直接下载可能出现“已损坏”提示；项目维护的 cask 会自动移除 Qterm 的隔离属性。

尚未安装 Homebrew？前往官网 ↗

首次安装

brew tap qiubai-lab/tap
brew trust qiubai-lab/tap
brew install --cask qterm

brew trust 用于 Homebrew 6.0+ 首次确认信任项目的 tap；旧版可跳过这一行。查看 tap ↗

更新 Qterm

brew update
brew upgrade --cask qterm

Windows

x64

在 GitHub 发布页的 Assets 中下载 .msi 或 .exe 安装程序，运行后按提示完成安装。

更新时下载最新版本的安装程序并运行。

x64

更新时安装最新软件包，或替换原 AppImage 文件。
