01 / WORKSPACE

自由组织工作区

本地终端与远程 SSH 会话自由分屏。切换任务时，保留正在运行的会话和布局。

02 / REMOTE

贴近远程开发流程

跟随终端当前目录打开文件和仓库。将本机资料交给远程 Agent，查看进度与结果。

03 / REVIEW

修改就在眼前

通过 SFTP 查看与编辑文件，在 Git 面板检查差异、暂存、提交和处理冲突。
