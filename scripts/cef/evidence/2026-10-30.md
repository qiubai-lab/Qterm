# dev-cef 验证结果（2026-10-30）

本次嵌套弹窗、主窗口退出回收验证和普通版本重新打包已完成。代码在
`dev-cef` 工作树，未提交、合并、推送、安装或发布。完整迁移规格仍保持
active：跨平台、完整原生交互与站点存储清理的缺口见下文。

## 修复与验证

- 按连接身份复用 RequestContext 和稳定 SOCKS 网关；创建同连接新网页时
  不重写代理。两个连接持续 HTTP 请求和原有 WebSocket 在 12 次网页开关期间
  均未中断，原生 `is_same` / `is_sharing_with` 检查通过。
- 保留独立原生 Alloy 弹窗，保留 POST、opener、Cookie 和 SSH 上下文。
  针对 CEF 154 的 macOS 窗口关闭后视图仍被持有问题，完成正常原生关闭握手后
  分离该 browser 的视图，等待原生关闭确认；弹窗家族归属使用根 webview ID。
- 每轮 40 次弹窗关闭循环，包含立即关闭、加载后关闭、10 次嵌套创建，分别覆盖
  中间窗口关闭时递归关闭后代、根页面关闭时回收全家族；其他连接持续可用。
- 主窗口退出前保留两个连接、两个活动 WebSocket 和两级弹窗。通过真实
  `plugin:window|close` 触发前端保存和 `web_shutdown`，验证 guests、environments、
  pooledContexts 均为零、所有私有网关端口关闭、捕获的 CEF 子进程全部退出。
- 最后 owner 断线、零网页断线、同身份其他 owner 存活、持久 Cookie 重开、
  关闭失败隔离与重试、客体 IPC/内部地址拒绝、IPv4/IPv6 无直连回退均通过。

同一测试二进制连续两轮 **139/139** 检查通过，共 80 次弹窗关闭循环。
测试二进制 SHA-256、逐项结果与包校验见 [verification.json](verification.json)
和 [package.json](package.json)。之前 Chrome-style 弹窗尝试发生崩溃，已移除；
旧测试通过记录不作为本次最终证据。嵌套测试通过子窗口自身的用户手势创建后代，
并明确断言窗口确实存在，避免把弹窗被拒绝误计为关闭成功。

## 内存实测

macOS 26.5 / arm64 / 16 GiB RAM；使用相同已验证测试二进制和真实独立 OpenSSH
fixture，加载完整 Qterm UI 与合成 HTTP 页面。单独运行 `measure_usage.py`，
没有同时构建或执行压力测试。每阶段等待 3 秒后取 5 个样本，表内为中位数。

| 状态 | 进程树 footprint | 进程树 RSS 总和 |
| --- | ---: | ---: |
| 仅主窗口 | 302.84 MiB | 796.73 MiB |
| 一个 SSH 网页 | 325.98 MiB | 919.27 MiB |
| 两个独立 SSH 网页 | 352.68 MiB | 926.23 MiB |
| 网页全关闭，连接 owner 仍存活 | 438.84 MiB | 705.91 MiB |
| 全部连接环境回收 | 314.04 MiB | 650.77 MiB |

footprint 来自 macOS `footprint` 对同一完整进程集合的 Summary Footprint；
RSS 相加会重复统计共享映射。Chromium 缓存、压缩及异步回收使数值波动，
关闭网页不代表立即释放上下文，也不能把两种指标相减解释为泄漏。
最小值、最大值及采样口径保存在 verification.json；这些是特定合成负载的
测量值，不是复杂开发站点的内存上限。早先压力测试阶段的测量未用作此表。

## 覆盖边界与剩余限制

1. 原生执行只验证 macOS arm64；Windows/Linux Web Block 能力在本分支暂时禁用，
   需要各平台 surface adapter 和真实运行验证。
2. 使用同一台机器上的两个临时 sshd。localhost:3000 场景经实际 OpenSSH
   隧道，仅 SOCKS 目标端口做 fixture 转换，HTTP Host/Origin 不改写；另一个阶段
   使用 Qterm 的真实 russh 会话、认证、SOCKS 与断线 watcher，目标为各自随机端口。
   未连接 HOME-220 或用户保存的服务器。
3. 全 profile 站点存储清理未实现；选中该项会在任何数据修改前明确报错。
   Cookie 与 HTTP cache 清理已验证。不能用“当前打开的 origin”冒充全部站点数据。
4. 完整键盘编辑、文件选择、原生焦点和所有遮挡视觉交互的人工验收尚未完成。
   弹窗按已批准方案为独立原生窗口，不接管为 Qterm 内部标签。
5. 新建上下文的网络门禁、页/worker 拒绝和 Service Worker 存储隔离已覆盖；
   磁盘恢复的 Service Worker 在页面创建前自主联网的专项时序尚未直接观测。
6. 普通包的 System/钥匙串路径由编译配置确认，未使用真实用户配置再次启动验证；
   Mock 测试中的 Cookie 持久化不等于真实钥匙串集成已验收。
7. Tauri 3 / CEF 集成仍依赖 alpha API 和仓库内补丁，升级须重新做这些回归。
   没有禁用证书校验或 sandbox；旧 WebKit/WebView2 存储保留，未自动迁移。

完整复现命令与构建依赖见 [README](../README.md)。本次验证不构成三平台发布就绪结论。
