# 配置合并分步界面重设计

## Behavior Delta
### MODIFIED
- REQ-001：独立步骤组件显示选择来源、确认合并、完成；当前目录复用通用设置卡片，来源采用自适应虚线选择框，选择成功后同位置替换为路径卡片，再由底部合并按钮进入确认阶段。
- REQ-002：凭证默认不选；选择凭证打开独立密码验证弹窗，成功后返回确认页。当前库未就绪时复用初始化或解锁流程。类别变更自动生成预览，最终确认提交。
- REQ-003：主弹窗固定 620 × 536 像素并受视口约束，固定步骤栏与底栏，长内容内部滚动；错误反馈不改变外框尺寸。
- REQ-004：前端不保留已提交密码；后端只在当前合并会话复用来源解锁状态，绑定来源快照与十分钟有效期，取消、取消凭证选择和提交时清除。

## Acceptance
- AC-001（REQ-001）：取消目录选择可重试；选择来源不自动跳步；可返回重选。
- AC-002（REQ-002）：默认凭证关闭，密码错误留在子弹窗，取消验证保持不选；成功返回确认并可直接提交；网络仍依赖连接。
- AC-003（REQ-003）：来源、确认、成功阶段外框一致，密码窗口显示在父窗口上方且正确获取焦点。
- AC-004（REQ-004）：选项变化无需重复传密码；来源改变、取消会话或取消凭证选择后不能复用旧解锁状态。

## Implementation
展示由 MergeSteps、MergeDirectoryCard、MergeConfirmation、MergeCredentialUnlock 负责；useConfigurationMerge 编排阶段和 IPC。既有规则、事务写入和目标路径确定方式不变。存储适配器管理临时来源解锁密钥，前端不接触密钥材料。

## Verification
- AC-001 / AC-002 / AC-003：8 项相邻 React 测试，覆盖阶段切换、默认值、嵌套焦点和层级、错误重试、提交刷新与固定布局。浏览器使用独立示例数据走通来源选择、验证与完成，截图确认外框和滚动区；没有操作真实配置。
- AC-004：12 项合并 Rust 测试通过，新增来源解锁复用与失效回归。
- 全量前端测试 1204 项通过，2 项跳过；脚本测试 17 项通过，2 项因 Bash 不可用跳过。全量 lint/source-size 通过；修正测试查询类型后 TypeScript 与生产构建通过。最终层级修正后重新运行相邻测试、lint 和 TypeScript。
- Rust clippy 全目标全特性通过，rustfmt 已执行。浏览器示例验证不替代原生目录选择或真实密码库的桌面人工测试。

## Session lifetime
有效期在下次使用时检查；缓存密钥不包含来源密码。取消、提交和取消凭证选择主动释放。当前库初始化属于现有持久操作，取消合并不会删除已初始化的空库。
