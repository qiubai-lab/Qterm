# 工作区通知气泡与未读动效

用户已采纳前台分工作区提醒方案并授权实施。范围为前端通知分发和工作区标签，不改协议、原生权限、CLI 配置或持久化格式。

## Requirements / Acceptance
- REQ-001 / AC-001：Qterm 前台且通知来自非当前工作区时，在来源标签下展示气泡，不发送系统通知；当前终端已聚焦则忽略，同工作区其他终端仅未读，后台仍走系统通知。
- REQ-002 / AC-002：气泡 4 秒后消失；悬停或键盘焦点暂停倒计时；同工作区合并计数并刷新倒计时，跨工作区以最新气泡替换以防重叠，未读独立保留。
- REQ-003 / AC-003：点击气泡切换来源工作区并聚焦来源终端；关闭/到期不标记已读，仍由实际终端聚焦清除。关闭工作区、过期会话、关闭通知或应用进入后台清理气泡。模态/锁定界面不展示气泡。
- REQ-004 / AC-004：非选中未读标签采用主题通知色（赛博红）的低强度 3 秒呼吸，3 次后静态保留，选中态保持原样；小圆点保证不只依赖颜色，减少动态效果偏好禁用动画。
- REQ-005 / AC-005：正文遵循已有开关，默认通用提醒；无抢焦点，支持键盘点击、Escape 关闭；标签溢出时气泡停靠可见标签栏边缘并明确工作区名。

## Design Constraints
复用现有 inbox 和会话 epoch，不引入第二套会话状态。瞬时气泡由通知域管理，布局定位和倒计时由气泡组件管理。WorkspaceShell 不增加状态或逻辑。遵循 Qterm 紧凑界面和 source-size 门禁。

## Behavior Delta
### ADDED
REQ-001、REQ-002、REQ-003、REQ-005：补充前台非当前工作区气泡、合并与定位。
### MODIFIED
REQ-004：原工作区未读圆点增强为弱呼吸提示，保留原选中样式。

## Quality
standard 内嵌检查通过：需求及验收闭合，无阻塞问题。采用轻量锚定气泡优于全局居中 toast，能表达通知来源；一次只显示最新气泡避免遮挡。
