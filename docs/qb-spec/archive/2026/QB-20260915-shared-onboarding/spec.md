# 两端共享首次使用引导

## Requirements

- REQ-001: 首次启动在工作区就绪且无阻塞弹窗后展示；展示即记录，跳过或重启不重复，更新不触发。
- REQ-002: 两端共享欢迎、工作区、终端、文件、Git、网络步骤与高亮组件，不自动执行终端命令或文件操作。
- REQ-003: Demo 主题旁提供重新引导按钮，主题保持居中；完成后重看入口高亮 2.4 秒后恢复。
- REQ-004: 应用端在最后一步引导用户点击实际关于按钮；打开关于即完成，弹窗内提供说明及使用引导按钮并短暂高亮。手动重看先关闭关于再从头开始。
- REQ-005: 支持跳过、上一步、键盘 Escape；认证等弹窗出现时暂停，目标不可见时使用说明回退，适配窄屏和 reduced-motion。

## Behavior Delta

### ADDED
- REQ-001: 稳定的本地首次展示记录，不与应用版本关联；桌面 WebView 和浏览器使用各自 origin 的 localStorage，并使用不同 key，数据不可用时退回当前进程内存记录。
- REQ-002: onboarding 独立拥有内容、状态和展示，不吸收 Workspace 业务。
- REQ-003: Demo 独立重看入口和结束强调。
- REQ-004: 桌面关于中的手动重看入口与结束路径。
- REQ-005: 启动/弹窗协调和可访问展示。

## Acceptance

- AC-001 [REQ-001]: 首次展示、跳过后重挂载不自动显示、手动重看可用；记录不包含应用版本。清除 WebView/浏览器数据会重置首次记录，不要求跨卸载或清除数据保留。
- AC-002 [REQ-002, REQ-005]: 各步骤可前进后退/退出，锚点随布局更新，不存在时不阻塞；不调用真实业务操作。引导不覆盖认证弹窗。
- AC-003 [REQ-003]: Demo 主题中心不偏移，重看按钮手机可见；完成后短暂高亮自动熄灭。
- AC-004 [REQ-004]: 桌面最终点击关于后结束引导，重看按钮出现且不会循环；点击重看关闭关于并重开第一步。
- AC-005 [REQ-005]: 自动测试与生产浏览器验证通过，完整 check 与两端构建通过。

## Implementation plan

1. 在 onboarding 中拆分展示记录、共享步骤、控制器、目标定位、卡片和重看按钮。
2. App/DemoApp 挂载 Provider，复用工作区 hydrated；桌面 shell 提供设置就绪和未锁定标识，既有弹窗优先。
3. 为工作区、终端、工具栏和重看入口添加稳定锚点；关于按钮和弹窗接入最终步骤。
4. 增加首次/跳过/阻塞/完成/重看测试；进行桌面与手机 Demo 浏览器验收、pnpm check、test:demo 和站点验证。

## Limitations

记录语义为本机 WebView/浏览器首次使用该引导。首次引入功能的旧安装没有记录时，也只展示一次；不推断安装程序事件，不读取联网更新结果。无后端协议或原生依赖变更。

## Verification

- AC-001: 自动测试验证首次展示、展示即记录、跳过后重挂载不再展示、手动重看及桌面就绪门槛；生产 Demo 刷新后无自动引导，手动入口仍可重新启动。
- AC-002: 生产浏览器走完七步，工作区、终端和工具入口高亮正常；测试验证其他 dialog 出现时暂停并在关闭后恢复，Escape 可结束。所有步骤只改变引导状态。
- AC-003: 1280px 视口主题中心 x=640；完成后重新引导入口具有 flash class，随后恢复。390×844 最新产物 scrollWidth=390、scrollHeight=844，重看入口和卡片可见；跳过后焦点恢复到重看按钮。
- AC-004: 集成测试使用真实 WorkspaceUtilityRail 与 HelpDialog，最终点击关于结束引导，真实弹窗中的使用引导按钮高亮；点击后关闭关于并重新展示欢迎卡，键盘焦点进入引导。
- AC-005: pnpm check 重跑全流程通过：1080 个前端测试通过、2 跳过，17 个 Node 工具测试通过，源码大小、ESLint、TypeScript、桌面前端生产构建通过。首次完整运行有两项既有异步测试超时，单独复查 15 项全部通过，串行重跑全套通过，未修改这些测试。
- test:demo 11 个文件、31 个测试通过；build:site 和 check:site 通过。浏览器控制台无 warn/error。reduced-motion 使用无动画静态强调，定时清除状态。

所有计划步骤完成；应用端完整 Tauri 窗口未做人工操作验收，以共享真实组件集成测试及桌面前端构建验证。没有原生依赖、IPC 或打包配置修改。
