# File Browser Download, Preview, and Edit

## Goal

用户能够在文件窗口中快速定位路径、下载远程文件或目录，并在不离开当前文件窗口的情况下预览和编辑常见文件。

## Scope

- 文件行提供鼠标和键盘可访问的右键菜单；远程文件与目录可选择本地保存位置并显示进度、成功、失败和取消状态。
- 路径显示组件采用与工作区标签一致的透明原位编辑，Enter 打开、Escape 取消；鼠标进入或滚动文件列表、访问目录以及点击其他操作时自动退出，失败时保留当前目录内容；刷新操作固定在导航栏最右侧。
- 文件首次单击只建立选中状态，再次单击已选中文件才在原文件窗口进入只读预览；右键菜单将“预览”和“编辑”拆分为独立入口，编辑入口和编辑界面均标注“实验”。
- 文件窗格底部保留单行窄状态栏：空闲时显示当前路径的文件夹/文件数量，下载中在同一位置替换为紧凑进度条，完成或失败后恢复统计并显示精简结果。
- Markdown 使用安全渲染预览，JSON、YAML 和普通文本使用只读语法预览；文本文件的实验编辑模式使用语法感知编辑器；JPG/PNG/GIF/WebP 仅提供图片预览。
- 预览工具栏右上角固定显示编辑按钮；支持文本编辑时按钮可用并直接切换到实验编辑，不支持编辑的文件保持按钮可见但禁用。
- 编辑工具栏在文件名后以星号标记未保存修改，并提供带图标的紧凑取消/保存按钮；取消明确放弃修改并直接返回列表，保存成功后移除星号。
- 保存按钮可见文案始终为“保存”且宽度固定；未保存时显示保存图标，已保存时显示勾选图标，状态变化不得造成工具栏位移。
- 本地和远程 UTF-8 文本支持带版本检查的保存；外部变化不得被静默覆盖。
- 远程保存显式创建并关闭同目录临时文件，继承原文件权限后再原子替换；任一步骤失败均清理临时文件并保留原文件。

## Constraints

- 文本编辑上限 2 MiB，图片预览上限 25 MiB；超限文件仍可下载。
- 目录下载不跟随符号链接，不覆盖或合并已存在的目标。
- Tauri command 只承担 DTO、选择器和错误映射；文件策略放在 application/domain，文件系统与 SFTP 放在 infrastructure。
- 二进制预览通过 raw IPC 返回，不使用 Base64/JSON 数组。
- 预览态是瞬时 UI 状态，不写入 Workspace 文档。

## Non-Goals

- 多文件标签、搜索替换、编码转换、十六进制编辑器和图片编辑。
- 下载目标覆盖/合并策略、多选批量操作、拖放传输。
- 跟随符号链接或下载设备文件、socket 等特殊文件。

## Acceptance

1. 远程文件和目录的右键菜单可通过鼠标、ContextMenu 键和 Shift+F10 打开，并可选择保存位置开始下载。
2. 文件下载复用原子临时文件；目录递归创建目标并聚合进度，取消或失败不会留下 `.terminal-demo.part` 文件。
3. 路径在原显示区域内以透明下划线样式支持编辑、提交和取消，编辑态不改变导航栏布局；进入/滚动文件列表、目录跳转或其他点击操作会退出编辑；刷新按钮始终位于最右侧；无效路径显示错误且保留最后成功目录。
4. 首次单击文件只选中且不读取内容，再次单击同一文件才在原窗格打开只读预览；返回后恢复文件列表上下文。
5. 文件右键菜单独立提供“预览”和“编辑（实验）”；图片不提供编辑入口，实验编辑界面持续显示实验标识。
6. 预览工具栏始终显示编辑按钮；文本预览中按钮可用并复用已读取内容切换到实验编辑，图片预览中按钮禁用。
7. 编辑内容变化后文件名出现星号，保存成功后消失；取消按钮不写入文件且直接返回当前文件列表。
8. 预览编辑、编辑取消和保存均使用低高度的图标文字按钮；编辑模式中“实验功能”位于“编辑”之前，文本光标使用与背景有明显对比的颜色。
9. Markdown、JSON、YAML、普通文本和图片使用相应只读预览；超限、非 UTF-8 或未知二进制文件得到明确提示。
10. 文本实验编辑具有脏状态、保存和离开确认；保存检测外部修改并拒绝静默覆盖。
11. 底部状态栏始终固定且高度不随传输状态变化；空闲时显示文件夹/文件统计，传输中显示进度，完成、取消或失败后恢复统计并显示结果。
12. 文件读取、保存、递归下载和 UI 状态具有正常、边界及失败路径自动化保护。
13. SFTP 文本保存可创建此前不存在的临时文件，等待写入确认后替换原文件，并保持原文件权限且不遗留 `.part`/`.backup` 文件。

## Open Questions

- 无阻塞问题；首期采用 UTF-8、禁止目标覆盖和不跟随符号链接的保守策略。

## Recommended Approach

采用 CodeMirror 6 按需语言支持、`react-markdown` 安全渲染、Tauri raw IPC 图片数据，以及独立文件应用服务。相比 textarea 方案，编辑和校验可持续扩展；相比 Monaco/IDE 方案，包体与运行复杂度更适合紧凑文件窗格。
