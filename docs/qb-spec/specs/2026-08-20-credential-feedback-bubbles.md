# Credential Feedback Bubbles

## Goal

凭证管理中的操作反馈应靠近触发操作所属的凭证项显示，并在短暂延迟后自动消失，避免固定在编辑区底部、遮挡删除等操作按钮。

## Scope

- 能明确归属到某个凭证的反馈，在该凭证列表项右侧显示轻量气泡。
- 新建密码、导入私钥、复制公钥及凭证详情读取失败均归属到对应凭证项。
- 删除后的提示、初始化刷新失败、主密码修改/恢复等无法稳定锚定到现存凭证项的反馈，使用管理级浮动提示。
- 成功反馈短时自动消失；错误反馈保留稍长，但同样自动消失。
- 新反馈替换旧反馈，并重新计算消失时间；关闭对话框时清理计时器。
- 凭证列表滚动或窗口尺寸变化时，单项气泡继续跟随锚点。

## Constraints

- 提示不得占用文档流高度，不得推动对话框尺寸变化，也不得遮挡固定底部操作区。
- 气泡不接管焦点、不阻塞鼠标操作，并遵循现有 Qterm 紧凑深色工作台视觉规范。
- 成功提示使用 `status` 语义；错误提示使用 `alert` 语义，不依赖颜色作为唯一信息。
- 凭证库锁定状态由标题状态、列表空状态和解锁入口共同表达，不再重复弹出短时提示。
- 不修改凭证 IPC、持久化格式或安全边界。

## Non-Goals

- 不引入全局 toast 框架。
- 不重做主密码、恢复密钥或删除确认弹窗内部的阻断式校验提示。
- 不改变现有凭证操作的业务语义。

## Acceptance

1. 复制公钥成功后，提示显示在对应私钥列表项右侧，不再出现在编辑区底部。
2. 单项成功提示会自动消失；错误提示具有更长但有限的显示时间。
3. 新建或导入成功后，提示锚定到新创建且已选中的凭证项。
4. 删除凭证、修改主密码、恢复主密码等特殊反馈使用不会遮挡底部操作区的管理级气泡。
5. 选择其他凭证、开始新建流程或收到新的反馈时，不会留下过期气泡。
6. 锁定凭证库不会显示冗余的“凭证库已锁定”气泡。
7. 现有新建、导入、删除、密码显示、公钥生成与复制行为保持可用。

## Acceptance To Verification

- React Testing Library 覆盖公钥复制气泡的凭证归属、自动消失和底部旧消息条移除。
- React Testing Library 覆盖删除后的管理级提示及锁定事件不产生冗余气泡。
- 运行 `pnpm vitest run src/components/dialogs/CredentialDialog.test.tsx src/app/appStyles.test.ts`。
- 最终运行 `pnpm check`。

## Open Questions

- 无。

## Recommended Approach

在 `CredentialDialog` 内维护单一短时反馈状态，区分 `item` 与 `manager` 两种作用域。单项反馈通过凭证按钮引用计算视口坐标，并使用 portal 渲染到顶层，以避免被列表滚动容器裁切；管理级反馈固定在编辑区右上方。组件统一负责计时、替换、ARIA 语义和卸载清理。
