## Goal

让用户直接通过文件列表表头按名称、大小或修改时间快速切换排序，并能恢复目录原始顺序。

## Scope

- 名称、大小、修改时间三个表头均可点击。
- 每列按“升序 → 降序 → 默认”循环，切换列时从升序开始。
- 默认状态严格保留目录接口返回顺序；主动排序时文件夹保持在文件之前。
- 当前排序列和方向同时通过视觉标识、提示文本和无障碍名称呈现。

## Constraints

- 排序只在前端派生，不修改目录数据、后端接口或文件操作逻辑。
- 未知修改时间始终排在同组末尾。
- 保持现有紧凑表头高度和三列网格对齐。

## Non-Goals

- 不持久化排序偏好。
- 不增加多列组合排序、筛选或后端分页排序。

## Acceptance

- 任一表头连续点击可按升序、降序、默认三态循环。
- 切换排序列时，新列从升序开始且只有一个活动排序列。
- 名称使用自然、大小写不敏感排序；大小使用字节数；修改时间使用时间戳。
- 文件夹在主动排序时位于文件之前；未知时间位于对应组末尾。
- 键盘可操作表头，当前状态不依赖颜色表达。

## Acceptance To Verification

- 使用 FileBrowserPane 行为测试验证三态循环、列切换、大小和时间边界。
- 使用样式测试验证表头按钮保持三列布局、可见焦点和活动指示。
- 运行 `pnpm check` 验证 lint、全部测试、类型检查和生产构建。

## Open Questions

无。

## Recommended Approach

保留 `listing.entries` 作为不可变原始顺序，通过组件内排序状态和 `useMemo` 生成展示列表。相比原地排序或后端排序，这种方式能精确恢复默认态，且不会影响刷新与文件操作。
