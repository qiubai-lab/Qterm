## Goal

让 Qterm 的桌面工作台形成统一、克制的半透明磨砂玻璃层级与圆角外观，同时保持终端内容的高对比度、紧凑布局和操作清晰度。

## Scope

- 让无边框 Tauri 主窗口支持透明背景，并使用原生窗口材质绘制带圆角的应用外壳。
- 在 macOS 启用透明窗口所需的 Tauri 私有 API；该方案面向当前桌面分发渠道，不以 Mac App Store 上架为目标。
- 为顶栏、右侧工具栏、终端标题栏和弹窗统一轻量色调、边缘高光与层级阴影，避免多层深色 alpha 叠加掩盖原生材质。
- 为应用外缘、终端分栏和既有交互控件统一圆角尺度。
- 为减少透明度与高对比度偏好提供实色降级。

## Constraints

- 保持终端画布为近黑色高对比内容层，不将文本直接放在动态透明背景上。
- 保持 40px 顶栏、62px 工具栏、紧凑分栏与现有 mint 语义色。
- 不引入新的 UI、动画或材质依赖。
- 不改变窗口控制、终端、文件与工具栏行为。

## Non-Goals

- 不重做信息架构、图标、业务流程或终端配色方案。
- 不给所有小元素叠加玻璃、阴影或胶囊外观。
- 不增加装饰性持续动画。

## Acceptance

- 应用外缘可见圆角，透明窗口区域不会显示不透明直角底色。
- 窗口后方桌面内容经过原生材质模糊，而不是仅显示深色半透明覆盖。
- 顶栏、工具栏、块标题和弹窗具有一致但有轻重差异的磨砂材质。
- 终端内容层仍保持近黑背景，活动分栏与工具状态仍清晰可辨。
- 系统要求减少透明度或提高对比度时，材质回退到近实色并保留边界。
- 现有前端检查通过。

## Acceptance To Verification

- 用样式测试断言窗口外壳、玻璃层和无障碍媒体查询的关键声明。
- 检查 Tauri 配置中的透明窗口、原生材质、跨平台回退顺序和原生圆角半径。
- 运行 `pnpm check`，并在桌面开发窗口中做聚焦截图检查（环境允许时）。

## Open Questions

无阻塞问题。

## Recommended Approach

推荐使用原生材质外壳加轻量 CSS 色调：Tauri `windowEffects` 在 macOS 创建 Behind Window 的系统材质，在 Windows 回退到 Mica/Acrylic/Blur；CSS 不再堆叠全屏模糊和高不透明度黑层。相比继续微调 CSS，这一方案能真实采样窗口后方内容；相比直接维护 AppKit/Win32 代码，它复用框架现有能力且维护成本更低。
